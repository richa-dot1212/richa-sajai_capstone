# Recipe Adaptation Agent

A Claude-based agent capstone project. A user gives a recipe URL plus what's different for them — missing ingredients, a different serving size, and/or different cooking utensils — and the agent adapts the recipe: it figures out what each missing ingredient does in that specific recipe, finds and validates substitutions (including checking how similar recipes use them), rescales quantities, rewrites instructions for the available equipment, checks the final recipe for consistency, and saves the personalized version to disk.
